# Сайт-портфолио: Саша и Архип

Монтаж вертикальных клипов и дизайн для стримеров и брендов.
Чистый HTML, CSS и JavaScript, без фреймворков и без сборки.

## Как обновить сайт

Почти всё меняется в одном файле — **`js/content.js`**:

| Что поменять | Где в файле |
| --- | --- |
| Ссылки на видео с YouTube | `verticalVideos` (9:16) и `horizontalVideos` (16:9), поле `url` |
| Картинки с дизайном | `designs`, поле `image` |
| Услуги и цены | `services`, поле `price` |
| Имена, роли, описания, фото | `team` |
| Telegram, Discord, почта, соцсети | `contacts`, поле `value` |
| Тексты на странице | `texts` |
| Языки сайта (RU, EN или оба) | `languages` |

Если поле пустое (`""`), на сайте показывается аккуратная заглушка.

### Как отредактировать прямо на GitHub

1. Откройте файл `js/content.js` в репозитории.
2. Нажмите на значок карандаша (Edit this file).
3. Вставьте ссылку или текст между кавычками `""`.
4. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.
5. Через 1–2 минуты изменения появятся на сайте.

### Как добавить картинки и фото

1. Откройте папку `images/works` (работы) или `images/team` (фото).
2. Нажмите **Add file → Upload files** и перетащите картинку.
   Лучше называть файлы латиницей без пробелов: `preview-1.jpg`, `sasha.jpg`.
3. Нажмите **Commit changes**.
4. В `js/content.js` впишите путь, например `"images/works/preview-1.jpg"`.

Перед загрузкой уменьшите картинки до 1600 px по длинной стороне —
так сайт будет грузиться быстрее.

## Файлы

- `index.html` — структура страницы
- `css/style.css` — оформление (цвета в самом верху файла)
- `js/content.js` — всё содержимое сайта
- `js/main.js` — логика: язык, видео, меню, контакты
- `images/` — картинки и фото
